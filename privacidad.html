Política de privacidad

Fabrica Bitu · Última actualización: 27 de noviembre de 2026

Quién usa la aplicación

Fabrica Bitu es una herramienta de uso exclusivo del dueño del canal de YouTube Bitu IA (@BituIA-ES). No está destinada a otros usuarios.

Qué permisos usa

La aplicación usa los permisos de la API de YouTube para subir y gestionar videos, administrar subtítulos y leer analíticas, únicamente sobre el canal del dueño.

Cómo se guardan los datos

Los tokens de acceso se almacenan cifrados de forma local en el equipo del dueño. No se envían a ningún servidor externo.

Uso compartido de datos

No se comparten, venden ni transfieren datos a terceros.

Cumplimiento con Google

El uso y la transferencia de la información recibida de las API de Google cumplen con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Consulta también las Condiciones del servicio de YouTube y la Política de privacidad de Google.

Cómo revocar el acceso

Puedes revocar el acceso de la aplicación en cualquier momento desde https://myaccount.google.com/permissions.

Contacto
